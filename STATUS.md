# Platform Console Status

The Dashboard now includes a permanent searchable usage-manual page in the lower-left auxiliary area and complete CRUD paths for providers, model deployments, routing policies, Bots, channels, context sources/bindings, capability bindings and schedules. Destructive actions use confirmations and dependency protection.

Primary navigation is grouped into workbench, configuration, operations and system administration. Configuration entities open on list views and enter dedicated create/edit states; advanced fields are only shown in those detail states. Capability management is split into inventory, import/update and builder views. The interaction contract is recorded in `docs/information-architecture.md`.

Version `0.1.0` is deployed. Better Auth accounts, roles, same-origin protected BFF, forced initial password change, all center management pages, local Bot chat, schedules, logs, diagnostics, Browser UI and read-only system assistant are implemented. “扩展与插件” adds Runtime Provider list/detail, Runtime Profile CRUD and cross-center extension list/detail with capability, probe, lifecycle and logs; lifecycle changes are admin-only. Complex forms keep common fields concise and expose advanced settings for provider headers/weights, model capabilities/pricing, channel adapter JSON, context scope, Bot safety modes, schedule retries and capability-binding triggers. Overview probes liveness, readiness and version independently; diagnostics collect only bounded, redacted operational metadata. Fifteen tests pass; the expanded navigation is included in release UI acceptance.
